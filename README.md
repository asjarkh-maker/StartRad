# Только да

Онлайн-приглашение на свидание, где ответ — только «да». Кнопка «Нет» убегает.

## Как это работает

1. Создатель собирает приглашение в пошаговом редакторе `/create`: имя, тема, способ открытия (конверт или кнопка), вопрос с фото и стикером, экран после «Да», выбор даты и времени, до трёх вопросов с вариантами (куда пойти, что поесть), финал. Справа — живое превью в телефоне.
2. Страница владельца `/m/<секретный ключ>`: превью, ссылка для отправки, статистика (открытия, попытки нажать «Нет») и ответ. Приглашение можно изменить, ссылка при этом остаётся прежней.
3. Получатель открывает `/i/<ссылка>`: конверт, вопрос с убегающей кнопкой «Нет», дата, выбор вариантов, финал.

В тексте можно использовать подстановки `{имя}`, `{дата}`, `{выбор}`.

## Запуск

На Windows: установите [Node.js](https://nodejs.org) (LTS) и дважды щёлкните `start.bat` — сайт откроется на http://localhost:3000.

Из командной строки:

```bash
npm install
npm start          # http://localhost:3000
```

Переменные окружения:

| Переменная     | По умолчанию | Что делает |
|----------------|--------------|------------|
| `PORT`         | `3000`       | порт сервера |
| `PRICE_RUB`    | `490`        | цена ссылки, ₽ |
| `PAYMENT_MODE` | `dev`        | `dev` — оплата подтверждается сразу; `off` — всё бесплатно; иное — нужна платёжная система |

Данные хранятся в `data/invites.json`, фото — в `data/uploads/` (в git не попадают).

## Что осталось сделать

- **Оплата.** В `server.js`, обработчик `/api/invites/:id/pay`, оставлено место под платёжную систему (например, ЮKassa): создать платёж, вернуть `confirmationUrl`, а `paid = true` выставлять в webhook.
- **Точное совпадение с оригиналом.** Тексты и вёрстка собраны по одному скриншоту главной страницы; остальные экраны сделаны по смыслу.

## Установка на сервер (Ubuntu/Debian)

```bash
bash deploy/setup-ubuntu.sh                       # по IP-адресу
bash deploy/setup-ubuntu.sh example.ru me@mail.ru # домен + HTTPS
```

Скрипт ставит Node.js и nginx, запускает сайт как службу `tolko-da` и сам стартует после перезагрузки.

## Установка на Windows-сервер

В PowerShell от администратора, из папки проекта:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\deploy\setup-windows.ps1
```

Скрипт ставит Node.js (через winget), открывает порт в брандмауэре и создаёт задачу `TolkoDa`, которая запускает сайт при старте сервера. Сайт будет на порту 80; другой порт задаётся параметром `-Port`.
