# Только да

Онлайн-приглашение на свидание, где ответ — только «да». Кнопка «Нет» убегает.

## Как это работает

1. Создатель собирает приглашение на `/create`: имя, письмо, варианты даты и места, оформление.
2. Смотрит предпросмотр бесплатно, потом получает ссылку (в режиме `dev` — сразу, без оплаты).
3. Получатель открывает ссылку `/i/<id>`, нажимает на конверт, выбирает дату и место.
4. Создатель на странице `/r/<id>?key=<ключ>` видит ответ, число открытий и попыток нажать «Нет».

## Запуск

```bash
npm install
npm start          # http://localhost:3000
```

Переменные окружения:

| Переменная     | По умолчанию | Что делает |
|----------------|--------------|------------|
| `PORT`         | `3000`       | порт сервера |
| `PRICE_RUB`    | `490`        | цена ссылки, ₽ |
| `PAYMENT_MODE` | `dev`        | `dev` — оплата подтверждается сразу; `off` — всё бесплатно; иное — нужна платёжная система |

Данные хранятся в `data/invites.json` (в git не попадают).

## Что осталось сделать

- **Оплата.** В `server.js`, обработчик `/api/invites/:id/pay`, оставлено место под платёжную систему (например, ЮKassa): создать платёж, вернуть `confirmationUrl`, а `paid = true` выставлять в webhook.
- **Точное совпадение с оригиналом.** Тексты и вёрстка собраны по одному скриншоту главной страницы; остальные экраны сделаны по смыслу.
